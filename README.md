# 双区智能存储系统 DPIM
> Double-Place Intelligence Memory 
>
> 版本：v0.2.1

## 系统简介

- 双区智能存储系统，即DPIM，是一个信息存储系统，采用AI功能可选且作为辅助的模式，使用信息图谱与信息资源相互映射而分离管理的存储特色。
- 主要功能定位为数据资源库与对话资源存储，近似于本地维基或小图书馆。
- 暂时不推荐多存（SQLite），支持异步读取，技术栈中配套资源较为初级，后续会升级。
- 系统构建有使用AI辅助，部分功能合理性与界面美观性有待商榷，如出现问题请及时联系。


## 快速使用

### 存储系统dpim

```bash
cd dpim
uv sync                       # 首次：同步环境
uv run python main.py serve   # 启动服务，默认 :8000
```

- 启动后访问 http://localhost:8000/docs 查看接口文档。

### 管理面板Web UI

```bash
cd dpimWebUI
pnpm install
pnpm dev      # 默认地址：http://localhost:5173
```

### 命令行管理

```bash
uv run python main.py ingest "用户询问了 Python 异步编程"   # 写入事件
uv run python main.py query "Python 异步"                    # 检索
uv run python main.py status                                 # 查看状态
```

### CLI（非必须）

```bash
cd dpimCLI
pip install -e .
dpim --help   # 13 命令 / 23 操作（详见 dpimCLI/README.md）
dpim shell    # 交互式 Shell
```

## 核心特性

- **双区存储**：不可变事件日志（SQLite + FTS5）+ 知识图谱（NetworkX + JSON），双向溯源
- **智能可选**：Cr/In/Gr/Meta 四角色 Agent 管线自动衍生结构化知识，无 AI 时降级为基础全文检索
- **降低错觉**：每条图节点锚定来源事件，元认知裁判做子串校验
- **自动维护**：AI自动扫描冗余节点并合并、删改（降级保连接、恢复自动补偿）

## 注意事项
1. 安装与启动，请参照快速启动部分的说明。
2. 读写与配置，可以通过dpim本身的各个文件完成。更推荐使用控制面板（Web UI）进行控制。
3. 可手工传入知识节点，也可自动传入知识节点，
4. 系统的Agent管线具有整体上下文围栏，也可以自行调整，以免上下文太短致使整合功能失效。
5. 如需要使用管理功能，请自行配置API，
6. 面向更大的数据量情况，将会在后续更新中支持。目前的目标节点为千条，但本版本的图渲染不算美观，请注意合理使用。
7. 如果需要集成到其他系统中，作为知识库或管理库，目前请自行开发接口（如MCP或Tool），或对本系统做适配（针对服务接口）。本系统的接口在使用时都可以调用，调用的实例可参考前端的设计。
8. 其他说明便是各个模块下的README。如不想阅读，则阅读这份就好，因其目前属于AI生成文件，文字量过大，不推荐阅读。

## 推荐的使用示例
以下给出一些简单的使用案例说明，以便更好了解其可用特性。

### 不动的小图书馆
- 作为可用的维基或知识网，管理知识信息。
- 可以在存储时使用智能体能力，而在使用时使用已经整合好的db与json文件，不一定强求智能体检索能力。

### 本地历史对话库与知识库
- 作为非传统知识库，请参考上一条案例。
- 可以使用其数据分类能力，分为对话（interaction）和数据（data）信息，当然也可以包含系统（system）信息。
- 作为用户使用历史，这边的interaction是可以支持的，但作为即时调用的上下文，目前会太慢了一些，推荐使用AGENTS.md注入上下文。

### 流水档案包
- 如前两个案例所述，便可以使用知识库特色。
- 在此基础上，因为其使用时序管理，所以可以用来存储流水数据。
- 如对流水数据构建索引，便可构成图谱，方便快速检索。
